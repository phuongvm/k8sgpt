# k8sgpt Project Overview

**Purpose**: 
k8sgpt is a tool for scanning Kubernetes clusters, diagnosing, and triaging issues in simple English. It codifies SRE experience into its analyzers and helps pull out the most relevant information to enrich it with AI.

**Tech Stack**:
- **Language**: Go
- **Infrastructure**: Kubernetes
- **AI Backends**: OpenAI, Azure, Cohere, Amazon Bedrock, Google Gemini, and others.

**Key Features**:
- Workload health analysis
- AI-powered explanation of issues
- Integration with various AI providers
- CLI tool structure
